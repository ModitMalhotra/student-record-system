# student-record-system

# Description
A console-UI C++ application that allows users to add, view, and search student records by their roll numbers. The data is stored in a text file using file handling to ensure persistence across sessions.

# Features
- Add new student records (roll number, name, marks)
- View all existing student records
- Search for a student by roll number
- File-based storage using `.txt` format

# Technologies Used
- C++ Programming Language
- File Handling (`ifstream`, `ofstream`)
- Structures
- Console UI (Text-based menu system)

# How to Run
1. Open a terminal or command prompt.
2. Compile the code using a C++ compiler
